# TMDB Movie App

Um app simples em React Native para explorar filmes da TMDB API.

## Setup

1. Instale as dependências:
```bash
npm install
npx expo install
```

2. Execute:
```bash
npm start
```

3. Pressione `a` para Android ou `w` para web.

## Features

- Lista de filmes populares
- Busca de filmes
- Detalhes do filme
- Favoritos (persistidos localmente)
